# پروژه عامل هوشمند بازی دوز (Tic-Tac-Toe) - گام اول
**درس:** آزمایشگاه هوش مصنوعی  
**مدرس:** سرکار خانم فاطمه جوکار  
**اعضای گروه:** محمدامین فراتی، مهدی ظلی‌پور، علی احمدی، عرفان دهستانی  

---

## ۱. تعریف مسئله
هدف این پروژه، طراحی و پیاده‌سازی یک عامل هوشمند عقلانی برای بازی دوز (Tic-Tac-Toe) است. عامل باید بتواند در برابر حریف (انسان یا عامل تصادفی/هوشمند دیگر)، بهترین خانه‌های ممکن را با هدف بیشینه‌سازی احتمال پیروزی یا تضمین حداقل نتیجه مساوی برگزیند. الگوریتم اصلی مورد استفاده در فازهای نهایی، الگوریتم جستجوی خصمانه **Minimax** به همراه **هرس آلفا-بتا (Alpha-Beta Pruning)** خواهد بود.

## ۲. چارچوب ساختاریافته PEAS

| مؤلفه | شرح در بازی دوز |
| :--- | :--- |
| **معیار عملکرد (Performance)** | • نرخ پیروزی در ۱۰۰ بازی متوالی<br>• عدم شکست در برابر حرکات بهینه (تضمین مساوی)<br>• کمینه‌سازی تعداد حرکات تا برد<br>• کمینه‌سازی زمان تصمیم‌گیری در هر گام |
| **محیط عملیاتی (Environment)** | • صفحه مشبک ۳×۳ با ۹ خانه<br>• رقیب روبرو (با رفتار غیرقابل پیش‌بینی یا بهینه)<br>• قوانین رسمی نوبت‌دهی و ثبت علائم (X و O) |
| **محرک‌ها (Actuators)** | • ثبت علامت در یکی از خانه‌های خالی معتبر (اعداد ۰ تا ۸ یا مختصات سطری-ستونی) |
| **حسگرها (Sensors)** | • دریافت ماتریس وضعیت جاری صفحه بازی<br>• تشخیص نوبت بازیکن فعلی<br>• حسگر پایان بازی (بررسی وضعیت برد، باخت یا پر شدن صفحه) |

## ۳. ویژگی‌های شش‌گانه محیط پروژه

| ویژگی محیط | وضعیت در دوز | توجیه علمی و فنی |
| :--- | :---: | :--- |
| **دسترسی به اطلاعات** | **کامل (Fully Observable)** | وضعیت تمام ۹ خانه صفحه بازی و موقعیت مهره‌ها در هر لحظه به وضوح برای هر دو عامل آشکار است و هیچ حالت پنهانی وجود ندارد. |
| **تعداد کنشگران** | **چندعامله (Multi-Agent)** | بازی دو نفره و رقابتی با مجموع صفر (Zero-Sum) است؛ سود یک عامل مستقیماً معادل زیان رقیب است. |
| **قطعیت** | **قطعی (Deterministic)** | انتخاب هر خانه بدون دخالت شانس انجام می‌شود و هیچ عامل تصادفی (مثل تاس) نتیجه یک حرکت را تغییر نمی‌دهد. |
| **توالی زمانی** | **ترتیبی (Sequential)** | هر حرکت مستقیماً آرایش صفحه را تغییر داده و فضای تصمیم‌گیری و گزینه‌های حرکات بعدی را محدود می‌کند. |
| **تغییر پویای محیط** | **ایستا (Static)** | حین تفکر و اجرای الگوریتم توسط عامل، ساختار محیط و چینش مهره‌ها ثابت مانده و هیچ تغییری نمی‌کند. |
| **فضای حالت و زمان** | **گسسته (Discrete)** | تعداد حالات صفحه (حداکثر $3^9 = 19683$ حالت) و تعداد انتخاب‌های ممکن در هر مرحله کاملاً متناهی و گسسته‌اند. |

## ۴. سنجه ارزیابی عملکرد (Evaluation Metric)
معیارهای اصلی برای سنجش هوشمندی عامل عبارتند از:
1. **نرخ پیروزی و عدم باخت:**
   $$\text{Win Rate} = \frac{\text{Wins}}{\text{Total Games}} \times 100$$
   $$\text{Loss Rate} = \frac{\text{Losses}}{\text{Total Games}} \times 100$$
2. **میانگین زمان اجرای هر حرکت (Latency per Move):** بر حسب میلی‌ثانیه برای سنجش بهینگی الگوریتم.
3. **تعداد گره‌های پیمایش‌شده (Explored Nodes):** بررسی تأثیر هرس آلفا-بتا در کاهش فضای جستجوی درخت بازی.
